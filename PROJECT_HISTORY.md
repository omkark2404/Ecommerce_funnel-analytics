# Project History & Migration

This document serves to clarify the development timeline of the E-Commerce Product Funnel Analytics project.

## Development Timeline
*   **Original Development:** This project was originally architected, developed, and completed during the period of **April – May**. 
*   **Original Hosting:** The codebase was initially hosted on a separate GitHub account/repository which is currently inaccessible.
*   **Repository Migration:** On **September 29, 2026**, the original project files were downloaded from an archive and formally migrated to this main GitHub portfolio account (`omkark2404`). 

## Git History Notice
Because the project was migrated via a downloaded archive (ZIP), the original Git commit history, branching, and author metadata from April–May could not be preserved. 

The initial commit in this repository (dated September 29, 2026) represents the re-upload of the completed foundation. Subsequent commits on and after this date reflect a comprehensive portfolio-readiness refactoring phase, which included:
*   Splitting the monolithic SQL scripts into a reproducible pipeline.
*   Enforcing strict chronological sequence checks in the funnel logic.
*   Adding CI/CD workflows, Docker configurations, and generating data visualizations.

*Note: No commits have been fabricated or backdated. The Git history accurately reflects the exact date the migration and subsequent refactoring took place.*
